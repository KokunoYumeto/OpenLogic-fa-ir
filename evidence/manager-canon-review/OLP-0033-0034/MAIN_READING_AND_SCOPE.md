## Target-to-source meaning checks

- The repaired enumeration criterion reads: every nonempty enumerable set has a surjection from the positive integers. No such map exists into the empty set, although the empty set is enumerable by the chapter definition. The note is an explicit correction, not an undisclosed strengthening of a source theorem.
- The binary sequence has a value at every position. Its diagonal complement depends on the given list and differs from row k at position k. Swapping bit values is not reversing their order, and specifying every value by a rule is not finishing an infinite algorithm.
- In the power-set diagonal, k belongs to the new set exactly when k does not belong to row k. Membership and nonmembership directions, power-set membership, and the arbitrary index survive the translation.
- Reducing enumeration of B to enumeration of A means a solution for A yields a solution for B. The surjection goes from A to B; the exercise's injection goes from B to A. The translation does not reverse either direction.
- The characteristic sequence is determined by its input subset. Removing the unbound subscript is a notation clarification; no enumeration of all binary sequences is assumed.
- In the repaired example, the underbrace marks an initial finite block, followed explicitly by infinitely many more zeroes. Every input maps to the infinite constant-zero sequence; the all-one sequence is outside its image. The independent report proposed the same constant map pointwise; this presentation preserves the original prefix notation while fixing its type.
- The exercise concerns sets of pairs, not just pairs; all functions, not only computable functions; and partial functions with variable domains, not a second collection of everywhere-defined zero functions. Every exercise remains an exercise without an inserted solution.
